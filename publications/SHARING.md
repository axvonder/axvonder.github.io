## Verification

PDF signatures, titles, authors, DOI identifiers, sharing notices and first-page renders were checked. Files remain unchanged, including repository cover sheets where present. SHA-256 hashes and full source details are in `publications.json`.

Run `python3 publications/verify.py` from the website root to check the files, hashes, download links and disclosure targets.

All nine local PDF URLs returned the correct PDF content type and file hashes. A browser click started a PDF download without leaving the homepage. All ten disclosures expanded by click and collapsed by keyboard. Layouts were checked at 1000 px and 390 px widths. The expanded abstract did not cause horizontal overflow.
